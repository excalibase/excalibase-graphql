# One image per line: the Docker Hub path without docker.io/ or library/, then :tag, then
# @sha256:digest when the code pins one. `sh ci/mirror-images.sh guard` fails CI when a file names a
# Docker Hub image missing here. The platform repository keeps its own list.
#
# Adding an image: put its line here, then run the 'Mirror images' workflow in excalibase/excalibase
# (Actions, Run workflow) with engine_ref=<your branch>, so the mirror holds it before this PR merges.
# After the merge the daily run keeps it fresh. Until the image is mirrored, CI cannot pull it.
# Pinned: a line with @sha256 is copied by digest, and the compose files and Dockerfiles name the same digest.
